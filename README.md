# Portafolio Personal | Nereo Schmidt - MasitasIA

Mi portafolio y carta de presentación personal. Diseñado para mostrar mi trayectoria, habilidades y proyectos como desarrollador. Contruido en mi Framework favorito Next.JS y React, en el moderno lenguaje de TypeScript.

## 🛠️ Tecnologías Utilizadas

- **Framework:** [Next.js](https://nextjs.org/) (App Router)
- **Librería principal:** [React](https://react.dev/)
- **Lenguaje:** [TypeScript](https://www.typescriptlang.org/)
- **Estilos:** [Tailwind CSS](https://tailwindcss.com/)

## 📁 Estructura del Proyecto

```text
📂 src/
 ┣ 📂 app/               # Rutas de la aplicación (App Router)
 ┃ ┣ 📂 carrera/         # Página de trayectoria académica y profesional
 ┃ ┣ 📂 proyectos/       # Página principal de proyectos y repositorios
 ┃ ┣ 📜 layout.tsx       # Estructura principal (Navbar, Footer, etc.)
 ┃ ┗ 📜 page.tsx         # Landing page (Hero y Estadísticas)
 ┣ 📂 components/        # Componentes reutilizables de la interfaz
 ┃ ┣ 📜 Footer.tsx
 ┃ ┣ 📜 Hero.tsx
 ┃ ┣ 📜 HeroProyectos.tsx
 ┃ ┣ 📜 Navbar.tsx
 ┃ ┣ 📜 ProyectoCard.tsx
 ┃ ┗ 📜 Stats.tsx
 ┗ 📂 data/              # Datos locales de la aplicación
   ┗ 📜 proyectos.ts     # JSON/Array con la información de los proyectos
📂 public/               # Imágenes estáticas (Logo, fotos de proyectos)
```
